# Week 2 — Teacher Use Cases and Access Flow

## Overview

During Week 2, the focus was on organizing the teacher-related workflows and defining how instructors would interact with the system. The main objective was to connect functional requirements with real user actions inside the Teacher and Academic Staff Services module.

This included planning teacher login, assigned courses, weekly materials, assignment creation, attendance marking, grade entry, student viewing, and access control. Role-based access control was also discussed to make sure that teachers only access their own assigned courses and academic data.

## Documentation and Diagrams Worked On

During this week, the documentation focused on the first detailed analysis of the Teacher and Academic Staff Services module. The diagrams and notes prepared for this week included:

- Use Case Diagram for Teacher and Academic Staff Services
- Activity Diagram — Login
- Activity Diagram — Teacher Access Flow
- Activity Diagram — Academic Staff Access Flow
- User Scenarios
- RBAC notes

## Main Teacher Use Cases

The main use cases for the Teacher module are:

- Log in as instructor
- View instructor dashboard
- View assigned courses
- Open course detail page
- Upload weekly materials
- Create assignments
- Review student submissions
- Mark attendance
- Enter grades
- View enrolled students

## Outcome of Week 2

By the end of Week 2, the teacher use cases and access flows were clearly defined. This helped connect the functional requirements with real system behavior and prepared the module for frontend page planning, protected routes, and API integration.
