# Week 3 — Frontend Structure and Teacher Pages

## Overview

During Week 3, the focus moved from planning to the frontend structure of the Teacher and Academic Staff Services module. The main goal was to create the base pages used by instructors and organize them in a clear way.

The Teacher module needed a simple structure where the instructor could access the dashboard, assigned courses, course details, attendance, grades, materials, assignments, and students. This week also focused on planning reusable frontend components to avoid repeating the same UI elements in different pages.

## Main Pages Worked On

The main frontend pages planned for the Teacher module were:

- Instructor Dashboard
- My Courses
- Teacher Course Detail Page
- Weekly Materials Page
- Teacher Assignments Page
- Attendance Page
- Grades Management Page
- Students Section
- Academic Staff support pages

## Documentation and Diagrams Worked On

During this week, the documentation focused on the frontend structure of the Teacher module. The diagrams and notes prepared for this week included:

- Class Diagram draft
- Object Diagram draft — Teacher with Course Offering and Students
- Package Diagram — Teacher Module Structure
- Component Diagram — Frontend Teacher Pages
- Reusable component notes

## Outcome of Week 3

By the end of Week 3, the frontend base structure of the Teacher module was clearer. The main instructor pages were identified, the Teacher Course Detail Page was planned as the center of course-related actions, and reusable components were defined for dashboards, cards, tables, filters, forms, tabs, and status badges.
