# Diagrams

This directory organizes project diagrams by diagram family and type.

## Structure

- `Structural Diagrams/` contains class, object, component, composite structure, package, deployment, ER, and relational schema diagrams.
- `Behavioral Diagrams/` contains use case, activity, sequence, state, communication, interaction overview, timing, and BPMN diagrams.
- `Data Flow Diagrams/` contains context diagrams and Level 0, Level 1, and Level 2 DFDs.
- `Architecture Diagrams/` contains system, backend, frontend, and database architecture diagrams.

Existing diagram files are placed in the most specific matching folder when their names or contents clearly identify the diagram type.
